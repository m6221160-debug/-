# אפליקציית "שירים" – נגן מוזיקה אופליין

## בניית ה-APK (פעם אחת, בערך 10 דקות)
1. התקינו Android Studio (גרסה עדכנית) מ-developer.android.com/studio
2. File > Open ובחרו את תיקיית הפרויקט הזו. חכו לסיום ה-Sync (בפעם הראשונה צריך אינטרנט להורדת רכיבי הבנייה).
3. Build > Build Bundle(s) / APK(s) > Build APK(s)
4. הקובץ נוצר ב: app/build/outputs/apk/debug/app-debug.apk
5. העבירו אותו לטלפון, אפשרו "התקנה ממקורות לא ידועים" והתקינו.

## שימוש
1. העתיקו תיקיית שירים לטלפון (דרך כבל למחשב).
2. פתחו את האפליקציה ובחרו את התיקייה פעם אחת.
3. מכאן הכול עובד ללא אינטרנט. לאפליקציה אין בכלל הרשאת אינטרנט.

## בניית APK בלי להתקין כלום (GitHub)
1. פתחו חשבון חינמי ב-github.com ולחצו New repository (שם כלשהו).
2. לחצו "uploading an existing file" וגררו פנימה את כל תוכן התיקייה (כולל התיקייה הנסתרת .github), ואשרו Commit.
3. לשונית Actions > Build APK > Run workflow. אחרי כ-5 דקות היכנסו להרצה והורידו את Shirim-APK בתחתית העמוד.
4. פתחו את ה-ZIP שירד, והעבירו את app-debug.apk לטלפון.
